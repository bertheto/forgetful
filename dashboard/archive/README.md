# Dashboard V1 — Archive

This folder preserves the **original HTML-monolithic dashboard** (`dashboard-v1.html`, ~118 KB, 2348 lines)
that lived at `~/.cursor/tools/forgetful-dashboard/dashboard.html` before the Svelte 5 migration.

## Why keep it?

- **Read-only reference** — shows the baseline feature set (graph, stats, memory table, briefing, activity stream)
  that the Svelte 5 rewrite must preserve. Useful when debugging regressions.
- **Fallback** — if the Svelte app ever breaks catastrophically, the V1 can be opened locally (static HTML + CDN deps)
  pointing at the same `localhost:8020` backend. No build step required.

## Do NOT edit this file.

Any change must go into the Svelte source (`dashboard/src/`). Keep the V1 frozen as the post-migration snapshot.
